# 📚 Prácticas de programación

Bitácora de ejercicios y exámenes de mis cursos de programación. Muestra cómo empecé con la lógica de programación (ciclos, condicionales, acumuladores y contadores) en distintos lenguajes.

## C++ (`/cpp`)
| Archivo | Qué hace |
|---|---|
| `Castillo_Diego_ORD1.cpp` | Ferretería: registra clientes en un ciclo `while`, calcula descuentos por antigüedad e IVA, y lleva el total. |
| `Exa2_Castillo_Diego.cpp` | Becas: con un ciclo `for` evalúa a 10 estudiantes por promedio y tipo de beca, y cuenta becas otorgadas y negadas. |
| `sala_cine.cpp` | Cine: un `do-while` cobra boletos con descuentos según la edad y un número al azar, y valida la entrada con `while`. |
| `Castillo_Diego_Repasoexamen2_S13T2.cpp` | Nómina: calcula el sueldo según el puesto y las horas trabajadas con `switch` y `do-while`. |

## Java (`/java`)
| Archivo | Qué hace |
|---|---|
| `Castillo_exa1_Diego.java` | Seguros: calcula el monto de cobertura según el tipo de vehículo, los daños y los lesionados. |
| `Castillo_Diego_Exa2.java` | Librería: un ciclo `do-while` atiende clientes, aplica descuentos y cuenta cuántos clientes recibieron cada tipo de descuento. |
| `Sala_cine.java` | Versión en Java del ejercicio del cine. |
| `Castillo_Diego_Repasoexamen2_S13T2.java` | Versión en Java del ejercicio de nómina. |

## C# (`/csharp`)
| Proyecto | Qué hace |
|---|---|
| `figuras-mdi` | App de escritorio WinForms con formularios **MDI**: calcula área y perímetro de figuras y muestra una barra de progreso. Interfaz con Guna UI2. Abre el `.sln` en Visual Studio y restaura los paquetes NuGet. |

## 🛠️ Conceptos
`for` · `while` · `do-while` · condicionales · contadores y acumuladores · entrada y salida por consola · `switch` · validación de datos · WinForms (MDI)
